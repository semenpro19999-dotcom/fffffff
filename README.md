# World Studio — редактор мира для Minecraft (Fabric 1.20.1)

Мод в духе **Roblox Studio** прямо внутри Minecraft: выделяете регион жезлом, открываете
графическую панель и строите/редактируете мир как в редакторе — заливка, замена, стены,
оболочка, выдалбливание, копирование в буфер, поворот на 90°, вставка, отмена/повтор
и библиотека схем, которая хранится в папке мира.

> Целевая версия: **Minecraft 1.20.1**, **Fabric Loader**, **Java 17**.

## Что умеет

| Возможность | Как пользоваться |
|---|---|
| Выделение региона | ПКМ жезлом по двум углам (рамка рисуется в мире) |
| Панель редактора | Крадучись + ПКМ жезлом, либо клавиша `K`, либо `/ws` |
| Заливка / замена / стены / оболочка / выдалбливание / очистка | Кнопки панели или `/ws fill` и т.д. |
| Поиск блоков | Поле поиска в палитре: ищет по id и по названию (в т.ч. на русском) |
| Два режима палитры | «Ставить блок» и «Заменять из» |
| Буфер обмена | `Copy` → `Paste`; `Rotate 90` или клавиши `[` / `]` |
| Вставка с воздухом или без | Переключатель «Вставлять воздух» |
| История | `Undo` / `Redo` (на сервере, до `undoLimit` шагов) или Ctrl+Z / Ctrl+Y |
| Библиотека схем | Сохранение/загрузка/удаление NBT в `<мир>/worldstudio/` |
| Права | Одиночная игра всегда; на сервере — op-уровень из конфига |
| Команды | `/worldstudio …` (алиас `/ws`) — всё то же самое текстом |

## Как играть

1. Возьмите **Жезл студии** (в творческом инвентаре, вкладка «Инструменты», или `/ws wand`).
2. Кликните жезлом по двум углам будущей области — появится голубая рамка.
3. Крадучись + ПКМ (или `K`) — откроется панель **World Studio**.
4. Выберите блок в палитре и нажмите нужную операцию.
5. `Copy` копирует выделение в буфер, `Paste` вставляет его в точку, где вы стоите.
6. `Undo`/`Redo` откатывают любые изменения; схемы переживают перезаход в мир.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `K` | Открыть панель |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / повторить |
| `[` / `]` | Повернуть буфер на 90° |
| `F8` | Показать/скрыть рамку выделения |

## Конфигурация

`config/worldstudio.json` создаётся при первом запуске:

```json
{
  "requiredPermissionLevel": 2,
  "allowWhenNotDedicated": true,
  "allowCreativePlayers": true,
  "maxEditVolume": 524288,
  "maxClipboardVolume": 262144,
  "undoLimit": 16,
  "pasteIgnoresAir": true,
  "maxSchematicNameLength": 48
}
```

## Сборка

Нужны JDK 17+ и интернет. Сборка идёт через Gradle-враппер:

```bash
./gradlew build          # Linux / macOS
gradlew.bat build        # Windows
```

Готовый мод лежит в `build/libs/worldstudio-1.0.0.jar` — положите его в папку `mods`
клиента с установленным Fabric Loader и Fabric API.

Запуск игры с модом прямо из исходников: `./gradlew runClient`.

### Сборка в CI

Репозиторий настроен на сборку в GitHub Actions (`.github/workflows/build.yml`):
каждый push в рабочую ветку собирает мод и выкладывает jar в артефакты прогона
(Actions → прогон → Artifacts → `worldstudio-jars`).

## Архитектура (коротко)

- `src/main/java/com/worldstudio/` — общий код: предметы, сеть, команды.
- `edit/` — сердце мода: `RegionSnapshot` (палитра + сжатый массив блоков) используется
  и для undo/redo, и для буфера, и для схем; `EditExecutor` применяет операции на сервере.
- `net/` — протокол на кастомных payload-каналах Fabric (`worldstudio:*`). Клиент шлёт
  намерения, сервер проверяет права, применяет изменения и рассылает состояние панели.
- `client/` — панель (`gui/StudioScreen`), палитра блоков, рамка выделения в мире.
- Никаких mixin-ов: всё построено на официальных Fabric API, поэтому мод устойчив к
  обновлениям загрузчика.
